# 雷达—红外复杂低空目标智能识别算法设计方案

## 1. 任务定义

输入为同一批次采集的雷达时序 `.mat` 与红外视频 `.mp4`。两种模态成对提供，但存在未知时间偏移，可能还包含时钟漂移。算法输出整段记录的目标类别、置信度及各类别概率，并保留窗口级预测、时间对准结果和模态质量信息。

赛题关注无人机、鸟、风筝及其他近地小目标在超低空、超低速和复杂云背景条件下的精细区分。算法按信号级、点迹级、航迹级和红外目标级组织特征，不使用文件名类别作为推理输入。

## 2. 总体架构

```text
雷达 MAT ─→ MATLAB table/矩阵解析 ─→ 数值时序展开 ─→ 窗口统计/频谱/变化特征 ─┐
                                                                              ├─→ 三分支集成 ─→ 记录级类别
红外 MP4 ─→ 稀疏采样 ─→ 局部对比+帧差候选 ─→ 轨迹关联 ─→ 外观/运动/轨迹特征 ─┘
                          │
雷达活动曲线 ─────────────┴─ 红外活动曲线互相关 ─→ 固定偏移+线性漂移估计
```

模型包含：

1. 雷达分支：对雷达字段的统计、动态和频域特征建模；
2. 红外分支：对小目标候选、轨迹和局部运动特征建模；
3. 融合分支：拼接两模态特征、同步分数和质量指标；
4. 质量感知后融合：依据雷达有效率、红外跟踪率和同步置信度动态调整三分支概率权重。

## 3. 数据读取与防泄漏

训练文件名可包含 `class-*`，该字段只用于构造监督标签。特征表不包含文件名、目录、批号编码或起始时刻编码。推理接口直接接受雷达文件和红外文件路径，不解析类别字段。

验证以批号为最小隔离单元。同一批次切出的全部窗口必须位于同一训练折或验证折，禁止随机窗口划分。

## 4. 雷达处理

### 4.1 数据解析

读取顺序为：

1. 使用 `mat-io` 解析 MATLAB `table`、`timetable` 和 MCOS 对象；
2. 若为普通数值矩阵，回退到 `scipy.io.loadmat`；
3. 对复数信号拆分幅度、实部和虚部；
4. 对固定长度向量字段展开，对可变长度向量提取均值、标准差、最大值和能量。

若目标服务器无法安装 `mat-io`，可运行 `scripts/convert_matlab_tables.m` 将表格转成普通数值 MAT。

### 4.2 时间轴

优先识别字段名中包含 `time/timestamp/datetime/时间/时刻` 的列。若不存在明确时间戳，则使用红外视频时长作为雷达行采样率估计依据。该估计会写入特征缓存清单，便于后续核查。

### 4.3 雷达特征

对每个窗口、每个数值字段提取：

- 均值、标准差、极值、中位数、10%/90%分位数、四分位距；
- 均方根、一阶差分标准差、最大绝对变化；
- 主频、谱熵、分频带能量比例；
- 标准化差分能量活动曲线；
- 缺失比例、有效样本覆盖率。

当正式字段中包含 SNR、RCS、径向速度、距离、方位、俯仰、点迹编号和航迹编号时，上述通用特征会自动覆盖这些字段。后续可按字段语义增加微多普勒旋翼频率、航迹曲率、悬停比例等专项特征。

## 5. 红外处理

### 5.1 小目标候选

每个采样帧执行：

1. CLAHE 局部对比度增强；
2. 高斯背景估计与中心—周围局部对比响应；
3. 相邻采样帧绝对差分；
4. 融合局部对比和运动响应；
5. 高分位自适应阈值分割；
6. 连通域面积、形状和长宽比过滤。

该方法不要求初始框标注，可在云层背景下形成可运行的弱监督基线。

### 5.2 轨迹关联

使用常速度预测和距离门控关联候选目标。候选评分综合局部响应强度、面积和与预测位置的连续性。短时漏检时保留轨迹状态，连续漏检超过阈值后重置。

### 5.3 红外特征

每个窗口提取：

- 灰度均值、方差、高分位亮度和梯度强度；
- 帧差均值、高分位运动强度和局部对比度；
- 候选数量、面积、响应分数；
- 目标位置、速度、加速度和转向率；
- 轨迹路径长度、直线度和横纵向跨度；
- 运动、速度、加速度和转向率的主频与谱熵；
- 检测率和窗口覆盖率。

## 6. 跨模态时间对准

构建雷达活动曲线 `E_r(t)` 与红外活动曲线 `E_i(t)`，重采样至统一频率后做受限互相关：

```text
b* = argmax_b Corr(E_i(t), E_r(t-b))
```

映射定义为：

```text
t_ir = a · t_radar + b
```

其中 `b` 为固定偏移，`a-1` 为时钟漂移。长记录被划分为多个局部段，分别估计偏移后进行加权线性拟合，并将漂移限制在配置范围内。对准结果包含偏移、漂移 ppm、全局分数及局部估计点。

## 7. 窗口切分

默认窗口长度 10 秒、步长 5 秒。红外窗口通过对准映射到雷达时间轴，只有两模态覆盖率均达到阈值的窗口才进入训练。长记录最多保留配置数量的窗口，防止单一长视频主导训练。

训练时每个窗口的样本权重与该批次窗口数成反比，使每个批次对损失函数的总贡献近似一致。

## 8. 分类与融合

三个分支均使用 ExtraTrees：

- 对非线性和特征交互敏感；
- 无需特征标准化；
- 适合当前小样本、异构统计特征；
- 推理速度快，便于离线交付。

窗口级概率融合为：

```text
p = w_r p_r + w_i p_i + w_f p_f
```

权重由基础权重和模态质量共同决定。记录级概率使用窗口熵反向加权平均，低不确定度窗口贡献更高。

## 9. 评价设计

评价单位为完整批次，指标包括：

- Accuracy；
- Balanced Accuracy；
- Macro-F1；
- Weighted-F1；
- Log Loss；
- 混淆矩阵和逐类 Precision/Recall/F1；
- Macro-F1 的批次自助法 95% 置信区间。

当某类别仅有一个批次时，无法形成无泄漏且训练折包含全部类别的完整交叉验证。评价程序会跳过无效折或明确报告 `insufficient_grouped_data`，不会使用随机窗口划分伪造高分。

最终交付包含：

- `model/model.joblib`：雷达、红外、融合三分支模型及配置；
- `infer.py`：统一推理接口；
- `run.sh`：官方评测一键入口；
- `docs/algorithm_design.md`：算法设计方案；
- `report/test_report.md`：自动生成测试报告；
- 全部源代码和依赖清单。
